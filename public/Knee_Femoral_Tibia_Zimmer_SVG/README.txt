TEMPLATE FEMORAL A DAN TIBIA SIZE 1 — SKALA SEMENTARA

Isi:
- Femoral_A.svg: AP dan lateral dalam satu SVG, grup terpisah.
- Tibia_Size_1.svg: AP dan lateral dalam satu SVG, grup terpisah.
- Empat SVG *_AP dan *_Lateral: satu tampak per file untuk overlay/layer.
- Preview.png dan Kalibrasi.csv.

Semua SVG berisi path vektor hijau, tanpa bitmap dan tanpa latar putih.
Garis merupakan penelusuran raster asli; bukan rekonstruksi CAD presisi.
Ukuran dokumen dinyatakan dalam mm. Margin transparan 1 mm di setiap sisi.
Jarak antartampak pada SVG gabungan hanya tata letak, bukan posisi anatomi.

SUMBER DAN SKALA
Femoral: gambar A dari Fem-AB(2).png, NexGen Legacy LPS-FLEX.
Ruler(3).png berasal dari model CR-FLEX berbeda. Skala ruler dipindahkan
ke gambar LPS-FLEX dengan asumsi skala piksel kedua lampiran sama.
Kesamaan resolusi gambar tidak membuktikan kesamaan skala fisik.
Karena itu ukuran femoral belum terverifikasi terhadap data produsen LPS-FLEX.

Tibia: Tib-1(3).png, Size 1, Fluted Stemmed Option 5988-00-01.
AP: bentang horizontal berlabel ~50 mm. Lateral: proyeksi horizontal
bentang berlabel 41 mm. Tinggi menggunakan interval lokal 77 mm.
Titik pengukuran dibaca dari gambar yang dinormalisasi ke lebar 1000 piksel:
AP X 146–447; lateral X 699–913; Y 265–660.
Skala X/Y diterapkan terpisah. Dimensi lain pada gambar tidak konsisten,
sehingga skala tibia juga merupakan perkiraan, bukan dimensi terverifikasi.
Yang disertakan hanya tray, post dan fin atas; konektor dan stem extension
bertumpuk di bawahnya dikeluarkan. Batas pemisahan mengikuti garis tampak.

Tulisan 15% Enlarged tidak diterapkan lagi setelah kalibrasi dari dimensi.
Tabel size 1–6 dari percakapan sebelumnya tidak dipaksakan pada model
terbaru ini, karena identitas dan sistem ukurannya berbeda.
Pemilihan femoral A dan tibia 1 bukan pernyataan kompatibilitas implant.

PENGGUNAAN
Impor SVG pada ukuran asli/100%; jangan pilih fit-to-page bila ingin
mempertahankan ukuran dokumen. Aplikasi dapat mengubah skala saat impor.
Untuk akurasi klinis, diperlukan template resmi model yang sama dan
verifikasi kalibrasi pada radiograf. File ini belum divalidasi untuk
pemilihan ukuran implant atau perencanaan operasi.
